# Скрипты для сервера — необязательные

По решению владельца сервер не настраивается на автообновление с GitHub: статьи выходят по таймеру
в браузере (см. `_tools/blog/README.md`), а сайт обновляется на сервере вручную, как раньше.

Скрипты оставлены на случай, если позже понадобится:
- `setup-server.sh` — один раз: закрыть папку `.git` и служебные файлы, включить настоящую страницу 404,
  поставить пароль на `/admin/` средствами nginx и включить автообновление каждые 10 минут;
- `update-site.sh` — само автообновление (запускается cron, который ставит `setup-server.sh`).

Даже без автообновления стоит хотя бы закрыть `.git` на сервере: сейчас `https://itcompania.ru/.git/config`
открывается любому.
