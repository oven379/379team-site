# Генератор блога itcompania.ru

Страницы блога (`/blog/…`), `sitemap.xml` (блок блога), `llms.txt` (список статей) и `404.html`
собираются этим скриптом. Руками их не правим — правим исходники здесь и пересобираем.

## Как добавить статью
1. Текст статьи — `posts/<slug>.html` (только тело: абзацы, `<h2>`, списки, таблицы; без FAQ).
2. Описание — новый `dict(...)` в `posts.py`: заголовки, `date` (день публикации), FAQ, ссылки, призыв.
3. Сборка из корня репозитория:
   ```
   python3 _tools/blog/build_blog.py
   ```

## Публикация по дате
Статья с `date` в будущем не попадает на сайт, в блог, карту сайта и `llms.txt`, пока дата не наступит.
Поэтому статьи можно написать заранее, а в день выкладки просто пересобрать, закоммитить и отправить.

Предпросмотр всех статей, включая будущие (только локально, не коммитить):
```
BLOG_PREVIEW=1 python3 _tools/blog/build_blog.py
```
После предпросмотра запустите обычную сборку — она уберёт будущие статьи обратно.

Папка `_tools` не попадает на сервер (см. `.dockerignore`).
