# Генератор блога itcompania.ru

Страницы блога (`/blog/…`), админка `/admin/`, `404.html`, блок блога в `sitemap.xml` и список статей
в `llms.txt` собираются этим скриптом. Руками их не правим — правим исходники здесь и пересобираем:

```
python3 _tools/blog/build_blog.py
python3 _tools/pages/build_pages.py
```

## Как статьи выходят по таймеру (без настроек сервера)
- Собираются **все** статьи, включая будущие, и выгружаются на сервер обычным обновлением сайта.
- Скрипт `/assets/publish.js` показывает статью посетителям в её дату (`date`) в **10:00 по Москве**:
  карточка в блоге, «Читайте также», «Полезно почитать» на страницах услуг и ссылки в тексте
  появляются сами. До даты страница статьи показывает «Статья выйдет … в 10:00» с отсчётом.
- Поисковики видят тексты сразу после выгрузки. `sitemap.xml` и `llms.txt` содержат статьи,
  вышедшие на момент сборки, и обновляются при следующей выгрузке.

## Как добавить статью
1. Текст — `posts/<slug>.html` (только тело: абзацы, `<h2>`, списки, таблицы; без FAQ).
2. Описание — новый `dict(...)` в `posts_plan.py`: заголовки, `date` (день публикации), FAQ, ссылки, призыв.
3. Пересоберите сайт (команды выше), закоммитьте и выгрузите на сервер.

## Админка
`/admin/` — расписание с таймером. Вход по паролю проверяется в браузере (в коде только хеш).
Это защита от случайных глаз, а не от программиста: секретов на странице нет.
Сменить пароль — см. комментарий в `admin.py`.

## Светлая тема
Стили — `/assets/theme.css`, переключатель — `/assets/theme.js`. Подключаются ко всем страницам
скриптом `_tools/theme/apply_theme.py` (генераторы блога и страниц вызывают его сами).
По умолчанию — тёмная тема, выбор посетителя запоминается в браузере.
