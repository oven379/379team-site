# Страницы услуг и портфолио

`build_pages.py` собирает страницы услуг из `pages.py`, портфолио `/portfolio/` из `cases.py`
и блок «Примеры работ» на странице `/mobile/`. Оформление берётся со страницы `/internet-magazin/`.

```
python3 _tools/pages/build_pages.py
```

- **Новая услуга** — добавьте `dict(...)` в `pages.py` (цены и сроки — только подтверждённые).
- **Новый проект** — добавьте его в `cases.py`. `tags` — на каких страницах услуг его показывать.
  `confirmed=False` — проект не выводится, пока не подтверждено, что это наша работа.
- **Ссылки на статьи** в «Полезно почитать» появляются сами, когда статья блога выходит.
- Сборщик обновляет блок страниц в `sitemap.xml` и строки услуг в `llms.txt`.
  При правке текстов страниц поменяйте `PAGES_UPDATED` — это дата изменения в карте сайта.

На сервере страницы пересобираются автоматически вместе с блогом (`_tools/deploy/update-site.sh`).
